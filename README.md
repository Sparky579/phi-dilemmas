# 你接受什么，就要承认什么

一本互动哲学小书：十一个两难，一本会翻旧账的立场账本。

在线阅读：**https://phi.sparky.qzz.io**

每一章先抛出一个两难（拔一根头发会不会让你变秃？传送门通勤坐不坐？电车扳不扳？），你选一边之后：

1. 书会先替你选的这一边说说好话：它抓住了什么直觉，哪些严肃的哲学家也站在这里；
2. 再给出这一边的“附加条款”：你选了它，还得同时承认什么；
3. 然后展开相关的哲学概念。每个流派都有一张卡片，写明它针对这个选择**声称了什么**、**不能声称什么**；
4. 后面的章节会翻你的旧账。比如第 3 章你说换光零件的手机还是原来那台，到第 4 章它会问你：那你自己呢？

读到最后会生成一份立场报告，包括你的账本、三条倾向、选择之间的张力，以及根据你的选择组合出来的开放式问题。

第 6 章会在你选择之前把对你的“预测”封进信封，选完再拆；第 9 章在你定好世界规则之后，真的掷一次骰子让你投胎。

## 目录

| 章 | 两难 | 涉及 |
|---|---|---|
| 0 | 你只相信被科学证明过的东西吗？ | 自我驳斥、逻辑实证主义 |
| 1 | 拔一根头发，会让你变秃吗？ | 连锁悖论、模糊逻辑、认知主义 |
| 2 | 你确定自己不是 NPC？ | 笛卡尔、缸中之脑、摩尔、语境主义 |
| 3 | 换遍零件的手机，还是你那台吗？ | 忒修斯之船、数目同一、四维主义 |
| 4 | 传送门通勤，坐不坐？ | 洛克、动物主义、帕菲特 |
| 5 | AI 说它很难过，你信吗？ | 图灵测试、中文屋、感受质、困难问题 |
| 6 | 算法比你更懂你，你还自由吗？ | 决定论、相容论、法兰克福案例 |
| 7 | 电车难题：扳，还是不扳？ | 功利主义、义务论、双重效应 |
| 8 | 穿越回古代，你能说他们错了吗？ | 道德实在论、相对主义、情感主义 |
| 9 | 人生重开前，你选哪个世界？ | 社会契约、无知之幕、诺齐克 |
| 10 | 永远快乐的头盔，戴不戴？ | 体验机、亚里士多德、萨特、加缪 |

## 开发

```bash
npm install
npm run dev      # 开发
npm run build    # 构建到 dist/
npm run serve    # 零依赖静态服务 dist/（默认 127.0.0.1:8851，PORT 可改）
```

React 18 + Vite。正文字体是[霞鹜文楷屏幕阅读版](https://github.com/lxgw/LxgwWenKai-Screen)（OFL）。
选择只存在读者自己浏览器的 localStorage 里，没有后端，不收集任何数据。

## 内容结构

所有正文都在 `src/content/chN.js`，一章一个文件，结构和写作规范见 [CONTENT_GUIDE.md](CONTENT_GUIDE.md)。
立场报告的问题和倾向在 `src/content/report.js`。想加一章、改一段、补一条“翻旧账”，只需要改这些数据文件。
